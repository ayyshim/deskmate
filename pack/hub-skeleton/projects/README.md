# Projects

One folder per repo: `projects/<repo>/`. Start with `INDEX.md`.

| File | What it covers |
|---|---|
| `INDEX.md` | What the repo is, its stack, how to run it, and a table of the other docs |
| `architecture.md` | Structure, main flows, data stores, integrations |
| `modules/<module>.md` | One doc per module or app: models, endpoints, jobs, gotchas |
| `permissions.md` | How the repo enforces permissions |
| `testing.md` | How to run the tests, what they cover, what is missing |

Write a repo's docs when you first work in it and find nothing here. Keep them current when you change the code they describe. Reference code as `<repo>/<path>:<line>`.
